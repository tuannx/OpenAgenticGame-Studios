# Proposal: Non-text ritual cues (show, don't tell)

## Intent

Kids at 1.5–4m **cannot read** on-canvas English. Replace word walls with
pictograms, color signals, elemental VFX, drum pulses, and short SFX so both
shell rituals read as Danny Go–adjacent *format* without copying IP.
