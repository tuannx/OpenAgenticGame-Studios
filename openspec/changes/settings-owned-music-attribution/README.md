# Settings-Owned Music Attribution

M23 gives licensed music attribution one technical-surface owner: the existing
settings disclosure. Gameplay no longer carries a floating license card, while
the full track, artist, license, and modification notice remain visible and
linked whenever settings are opened.

Status: implemented and validated on 2026-07-21. Native/WASM/web/browser/HTTP
gates passed; the unchanged inherited `sharp` audit findings and attended audio/
device checks remain documented in `validation.md`.
