# Proposal

Build a family/party BrainBreak platform where one or two people in front of a
camera control short rhythm games with body movement. Two browser endpoints can
connect through an authoritative-host WebRTC room. Keyboard and gamepad remain
first-class fallback input sources.

## Non-goals for v1

- Accounts, cloud content publishing, remote video, hosted gameplay relay, and
  runtime ML training.
- Native desktop distribution or a mobile visual editor.
