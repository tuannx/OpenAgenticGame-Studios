# BrainBreak Motion Party

Status: implementation in progress

This change delivers a Macroquad WebAssembly motion-party game, a local visual
content studio, and Cloudflare-hosted WebRTC signaling. Camera frames and pose
landmarks remain on the player's device.

## Milestones

- M1: Macroquad web vertical slice and deterministic game core.
- M2: Browser pose bridge, local multiplayer, and three rhythm modes.
- M3: Visual content studio and portable content packs.
- M4: Cloudflare signaling, TURN credentials, and P2P rooms.
- M5: validation, production deployment, and live browser verification.

Validation evidence and residual risks are recorded here as milestones close.
